# First release scope and required semantic audit

## This package intentionally contains

1. Cumulative thread-based AERA foundations/current canon and core documents for five-layer World Clock.
2. Separate L0 chromatic existence, L1 six Transduction operation categories, Seven+Black Prophecies, six-step lifecycle, and explicit non-contamination firewall.
3. Inherited available world systems from MK147/MK231 and earlier Genesis Point/MK Ultra discussed in this chat (Alchemy Type 1–5, vaen, ru’ne/sigils, velis/Architect, ELDRIS/dungeons/domai, Genesis organisms, Raeon/Prism/maege glass/ER Foam placeholder etc.).
4. The first worked MK231 realization of AERA plus historical book-color and realm-color distinctions.
5. Portable standalone root CONSTITUTION, Codex instructions, source register, decisions and technical recovery ledgers.
6. Historical AERA v0.2 ZIP intact and its exact constituent Markdown files, plus curated high-value user-provided reference images with provenance and noncanon flags.

## This package intentionally excludes

- Cloned `_bricked`, MK147, MK231, MK157 or `_raeon` trees; 3 GB maths/game files; large MK Ultra PDF; unrelated local screenshots of computer folders.
- The full verbatim chat transcript (source accessible in chat surface, not exported programmatically here).
- A new mathematical theorem, precise unknown L0 equations, new AERA license, universal societal laws, completed seven-book manuscripts.

## Codex's publication receipt MUST state

- Actual GitHub `main` commit SHA and remote URL, not only local `git commit`.
- Root `CONSTITUTION.md` exists and matches staged expected payload.
- `_inbox` and downloaded ZIP untracked, `.gitignore` present.
- All ZIP payload files copied to intended root/path, no nested `AERA_FRESH_PUBLISH_*` folder.
- Manifest and per-file SHA checks passed.
- A decision-level audit showing named systems/terminology are present and status scoped, not missing because of path reorganizations.
- Explicitly no wholesale upstream project clone and no force-push.

## Bootstrap completeness ≠ full math migration

This is the **first durable current-AERA conversation corpus**, not the final promised exhaustive source integration. Later large-corpus migration will be an independent Codex pass after separate planning/authorization. AERA must not claim the multi-gigabyte mathematics has been copied here.
