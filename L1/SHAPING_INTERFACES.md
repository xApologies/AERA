# Shaping interfaces — configurable Transduction implementations

**Framework rule:** The six-stage Transduction lifecycle governs all magic. A **Shaping interface** is a local technical, biological, cultural or artifact-based method for carrying out some of those operations. AERA does not require a particular interface. Interface complexity should be handled by the author's own stories/institutions.

## Verified/described examples

| Interface | Exemplary organization | Scope |
|---|---|---|
| **Binding Circle and Binding** | Prepared large physical sigil + suitable identity-bearing resources/Genesis crystals; selected identity resolved into durable Binding; deployed PSSP geometry automates **Shape + Hold** | MK147/MK231 method; **optional** for others |
| **Fractal skin/tattoo manifolds** | Fractal geometry embedded or formed in skin as local energy-propagation manifold; conscious topology/energy interaction | Author recalls from earlier MK fantasy (e.g. MK117); original source recovery for exact rules |
| **Genesis stones** | Historical Genesis Point energy interaction interface | Example; detailed source recovery |
| **Card-wielder Shapings** | Author's proposed future system of cards encoding/deploying a Shaping interface | PROPOSED, **not** identical to the Raeon cultural game |
| **Living/shared-existence bindings** | Kira's Black Phoenix and five later Black companions; independent entity, consent/guardianship, reciprocal amplification | MK231 story-specific extraordinary interface |
| **Valnak** | MK157's specialized training/progression world uses different access conventions | Illustration; not imported into AERA as mandatory machinery |
| **Direct Architects** | Architects constrain local Genesis field topology, possibly creating temporary `velis` | Existing optional engineering discipline, not inherently a personal 'spell deck' |

The author may create additional interfaces without altering L0 math or the universal Transduction sequence. Interface compatibility depends on the chosen world and the underlying Genesis constraints; simply saying 'it is magic' is not a substitute for specifying the interface in their fiction.

## Bound/scaffold versus result

**Binding acquisition** (choosing/resolving an identity into a practitioner or object) is a separate preparation event from **using an existing Binding** (deploy scaffold and perform the universal six stages). PSSP = phase-state shadow projection is the working projection mechanism described in MK147. A `vaen` identity input is not necessarily the only possible source of a Binding identity. Exact stored architecture versus projected manifold terminology is open upstream.

## Social professional classification is independent

`maege`/`maegi`, `helkir`, Summoner, Augmenter and Architect describe how a civilization *categorizes practitioners*. A card-wielding helkir or a fractal-tattoo engineer is logically possible. No author must use those professional labels.
