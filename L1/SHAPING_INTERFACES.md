# Shaping interfaces — configurable Transduction implementations

**Framework rule:** The six-stage Transduction lifecycle governs all magic. A **Shaping interface** is a local technical, biological, cultural or artifact-based method for carrying out some of those operations. AERA does not require a particular interface. Interface complexity should be handled by the author's own stories/institutions.

## Three principal interfaces

The [current Layer One interface documents](INTERFACES/00_READ_FIRST.md) consolidate **Native Genesis / Neurogenesis**, **Binding Circles** and **Genesis Cards** as three principal optional methods. Each carries out Conceive → Shape → Hold → Resolve → Manifest → Release; prepared Shape/Hold adds no lifecycle stage. Additional compatible interfaces remain available.

- [Native Genesis](INTERFACES/01_NATIVE_NEUROGENESIS.md): consciously construct and sustain any admissible Shaping within the practitioner's capabilities. Multiple Shapings may draw from the same basin if energy, attention, bandwidth, Resolution and fatigue permit, unless an active card occupies that basin. Architects are one specialization, not the only native practitioners.
- [Binding Circles](INTERFACES/02_BINDING_CIRCLES.md): install reusable identity-resolved architecture whose PSSP deployment maintains Shape/Hold. Installed Bindings persistently occupy finite personal Genesis bandwidth; the illustrative roughly 60% CSR flight Binding is not a universal cost.
- [Genesis Cards](INTERFACES/03_GENESIS_CARDS.md): consciously couple to a maege-glass encoded manifold. An active card exclusively anchors every basin it requires **across all of that practitioner's interfaces**, not only other cards. Binding bandwidth occupancy and card basin exclusivity are separate constraints.

The [concurrency and authority record](INTERFACES/04_CONCURRENCY_AND_AUTHORITY.md) distinguishes recovered MK147/MK727 mechanics from new AERA author decisions. Card activation against an already-running conflicting Shaping, exact Binding bandwidth accounting and mixed ordinary/Black Card concurrency remain **OPEN**; no forced cancellation is inferred.

## Bound/scaffold versus result

**Binding acquisition** (choosing/resolving an identity into a practitioner or object) is a separate preparation event from **using an existing Binding** (deploy scaffold and perform the universal six stages). PSSP = phase-state shadow projection is the working projection mechanism described in MK147. A `vaen` identity input is not necessarily the only possible source of a Binding identity. Exact stored architecture versus projected manifold terminology is open upstream.

## Social professional classification is independent

`maege`/`maegi`, `helkir`, Summoner, Augmenter and Architect describe how a civilization *categorizes practitioners*. A card-wielding helkir or a fractal-tattoo engineer is logically possible. No author must use those professional labels.
