# Layer Four — Story Engine

The author defines all story plots, arcs, books, dialog, character decisions, reversals, world-state changes and narration. **AERA does not write authors' stories for them** and does not require every AERA book to be a seven-part saga.

- [`STORY_ENGINE.md`](STORY_ENGINE.md) — author narrative space, world causality, examples.
- [`AUTHOR_WORKSHOP_PENDING.md`](AUTHOR_WORKSHOP_PENDING.md) — high-level observed workflow, flagged **DEFERRED** for a later full tutorial.
- [`../examples/MK231/`](../examples/MK231/README.md) — one real ongoing saga illustrating AERA, not a universal narrative template.
