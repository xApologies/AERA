# Layer Two — World Engine = Environmental + Civilization Engine

Authors determine their planets, stars, geography, weather, ecosystems, politics, cultures, institutions, technology, economies and social traditions. These all occupy **L2** and inherit the Genesis possibilities/constraints from L0 and L1. AERA does **not** require MK147's romanticized early-modern society, a kingdom, guild system or an established set of native chromatic races.
