# Layer Three — Character Engine

The Character Engine provides a **space for an author to define organisms, minds, identities, abilities, social roles, relationships, and development** within the chosen L0–L2 world. AERA does NOT supply preassigned protagonists, species tiers, 'classes', plots, narrative fates or mandatory personal power curves.

Read [`CHARACTER_ENGINE.md`](CHARACTER_ENGINE.md). Kira, her shared-existence companions and dwarf/elf/human interpretations are **specific examples** of character and biological configuration rather than universal human rules.
